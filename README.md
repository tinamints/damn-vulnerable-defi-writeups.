# Damn vulnerable DeFi writeups
This repository is where I learn various Solidity smart contract vulnerabilities and Decentralized Finance (DeFi) concepts, and practice writing writeups. In addition, I write tailored writeups in 3 languages, in the hope that fellow learners who speak the same language can make use of them.

you can easily fork and run this. Clone with `git clone --recurse-submodules` to fetch the libraries. The dependency files are already included.

source: [dam vulnerable defi](https://github.com/theredguild/damn-vulnerable-defi)
